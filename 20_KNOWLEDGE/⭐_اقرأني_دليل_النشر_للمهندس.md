# ⚠️ القاعدة الذهبية الأولى

هذا المشروع فيه مجلد اسمه **`_shared`** (تحته شرطة سفلية في البداية).
**هذا المجلد هو الأهم في المشروع كله.** كل الصفحات تعتمد عليه.
**إذا لم ترفعه، لن يعمل أي شيء.** انتبه له في كل خطوة.

---

# 📋 ما ستفعله (نظرة عامة)

1. تجهيز قاعدة البيانات (Supabase) — تشغيل ملفات SQL.
2. رفع كل الملفات على GitHub (بما فيها `_shared`).
3. تفعيل الموقع (GitHub Pages).
4. التأكد أن كل شيء يعمل.

---

# 🗄️ الجزء الأول: قاعدة البيانات (Supabase)

## هل تحتاج هذا الجزء؟
- **إذا كانت قاعدة البيانات تعمل بالفعل** (المشروع كان منشوراً من قبل ويشتغل): تخطَّ إلى الجزء الثاني، لكن **شغّل ملف واحد فقط**: `GMT_BOTS_PERMISSIONS_FULL.sql` (انظر الخطوة 1-5).
- **إذا كانت قاعدة جديدة تماماً**: نفّذ كل الخطوات التالية.

## الخطوة 1-1: افتح Supabase
1. ادخل على موقع supabase.com وسجّل الدخول.
2. افتح مشروعك (أو أنشئ مشروعاً جديداً).
3. من القائمة اليسار، اضغط **SQL Editor**.

## الخطوة 1-2: شغّل ملفات SQL بالترتيب
افتح مجلد `_SQL` في المشروع. شغّل الملفات **بهذا الترتيب بالضبط**:

**افتح كل ملف، انسخ محتواه كاملاً، الصقه في SQL Editor، اضغط RUN. ثم انتقل للملف التالي.**

```
1. _SQL/DB1_MAIN/GMT_00_BASE_TABLES.sql
2. _SQL/DB1_MAIN/GMT_MASTER_SCHEMA_2026-07-13.sql
3. _SQL/DB1_MAIN/GMT_BOTS_2026-07-13.sql
4. _SQL/DB1_MAIN/GMT_BOTS_PERMISSIONS_FULL.sql    ← مهم جداً!
5. _SQL/DB2_STORE/GMT_00_BASE_STORE.sql            (إذا تستعمل المتجر)
6. _SQL/DB3_WARRANTY/GMT_00_BASE_WARRANTY.sql      (إذا تستعمل الكفالة)
7. _SQL/DB3_WARRANTY/GMT_WARRANTY_TRACKING_2026-07-13.sql
```

**ملاحظة:** إذا ظهر خطأ «already exists» (موجود مسبقاً)، تجاهله وأكمل — هذا طبيعي.

## الخطوة 1-3: ⭐ ملف صلاحيات البوتات (مهم!)
الملف رقم 4 (`GMT_BOTS_PERMISSIONS_FULL.sql`) يعطي البوتات صلاحية تسجيل كل شيء.
**بدونه، البوتات لا تسجّل التقارير.** تأكد أنك شغّلته.

## الخطوة 1-4: أضف كلمة سر أدمن نقاط البيع
في SQL Editor، الصق هذا واستبدل `اكتب_كلمة_السر_هنا` بكلمة السر التي تريدها، ثم RUN:
```sql
insert into gmt_settings (key, value) values ('admin_password', 'اكتب_كلمة_السر_هنا')
on conflict (key) do update set value = excluded.value;
```

## الخطوة 1-5: مفاتيح الاتصال (مهم للمبرمج الأصلي)
كل صفحة فيها مفاتيح Supabase (SUPABASE_URL و SUPABASE_KEY).
إذا كانت قاعدة جديدة بمفاتيح مختلفة، يجب تحديثها. **إذا كنت تستعمل نفس القاعدة القديمة، لا تغيّر شيئاً.**

# 📤 الجزء الثاني: رفع الملفات على GitHub

## الخطوة 2-1: افتح المستودع
1. ادخل على github.com وسجّل الدخول.
2. افتح المستودع (مثلاً `system55`) — أو أنشئ واحداً جديداً.

## الخطوة 2-2: احذف الملفات القديمة (إن وُجدت)
إذا كان المستودع فيه نسخة قديمة:
1. الأفضل: احذف كل المجلدات القديمة أولاً (لتجنب الخلط).
2. أو ارفع فوقها (سيستبدلها).

## الخطوة 2-3: ارفع كل الملفات ⚠️ الأهم
1. فك ضغط ملف المشروع على جهازك.
2. ادخل مجلد المشروع (ستجد فيه: `index.html` · `_shared` · مجلدات الصفحات · `20_KNOWLEDGE` · `_SQL`).
3. على GitHub: اضغط **Add file → Upload files**.
4. **اسحب كل المحتوى دفعة واحدة** (كل المجلدات والملفات).
5. **⚠️ تأكد أن مجلد `_shared` ضمن المرفوعات!** هذا أهم مجلد.
6. اكتب رسالة (أي شيء) في الأسفل، ثم اضغط **Commit changes**.

## الخطوة 2-4: تأكد أن `_shared` رُفع
بعد الرفع، في صفحة المستودع، **يجب أن ترى مجلد `_shared`** في القائمة مع باقي المجلدات.
إذا لم تره → أعد رفعه. **بدونه لن يعمل شيء.**

# 🌐 الجزء الثالث: تفعيل الموقع (GitHub Pages)

## الخطوة 3-1: فعّل Pages
1. في المستودع، اضغط **Settings** (الإعدادات، فوق).
2. من القائمة اليسار، اضغط **Pages**.
3. تحت **Branch**، اختر **main** (أو master)، والمجلد **/ (root)**.
4. اضغط **Save**.
5. انتظر 1-2 دقيقة. سيظهر رابط الموقع في الأعلى.

## الخطوة 3-2: صور الشعارات (ارفعها يدوياً)
هذه الصور غير موجودة بالمشروع — يجب أن يوفّرها صاحب المشروع:
| الصورة | ترفع في مجلد |
|---|---|
| truck.png | 16_TRACKING |
| canonlogo.png | 08_STORE و 10_WARRANTY_CREATE و 12_WARRANTY_SEARCH |
| shamcash.png · mark.png | 08_STORE |
| genrallogo.png | 10_WARRANTY_CREATE |

(إذا لم تتوفر الآن، الموقع يعمل لكن بعض الصور لن تظهر — ليست مشكلة كبيرة.)

# ✅ الجزء الرابع: التأكد أن كل شيء يعمل

## اختبار 1: مجلد `_shared` (الأهم!)
افتح هذا الرابط بالمتصفح (استبدل `system55` باسم مستودعك):
```
https://[اسم-الحساب].github.io/system55/_shared/gmt-core.js
```
- ✅ **إذا ظهر كود (حروف وكلمات كثيرة)** → ممتاز! `_shared` يعمل.
- 🔴 **إذا ظهر 404 (File not found)** → `_shared` غير مرفوع. ارجع للخطوة 2-3.

## اختبار 2: البوابة الرئيسية
افتح:
```
https://[اسم-الحساب].github.io/system55/
```
يجب أن تظهر صفحة فيها كل روابط النظام. اضغط أي رابط للتأكد.

## اختبار 3: الجرد (المهم)
افتح صفحة الجرد. يجب أن تحمّل **بلا رسالة خطأ**.
- ✅ إذا حمّلت المنتجات (أو ظهرت فارغة بلا خطأ) → ممتاز.
- 🔴 إذا ظهر «GMTCache is not defined» → `_shared` غير مرفوع. ارجع للخطوة 2-3.

## اختبار 4: تحديث قوي (مهم على الهاتف)
بعد النشر، إذا رأيت نسخة قديمة:
- **كمبيوتر:** اضغط `Ctrl + Shift + R`.
- **هاتف:** اضغط القفل 🔒 بجانب الرابط → معلومات الموقع → مسح البيانات.
