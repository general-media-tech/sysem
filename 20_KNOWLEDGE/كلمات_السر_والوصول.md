# 🔑 كلمات السر والوصول — GMT

> ملف مرجعي لكل طرق الدخول بالنظام. احفظه بأمان.

---

## 🔐 كلمة سر أدمن نقاط البيع
**مخزّنة بقاعدة البيانات** (ليست بالكود):
- الجدول: `gmt_settings`
- المفتاح: `admin_password`
- العمود: `value`

**لمعرفتها/تغييرها:**
1. افتح Supabase → Table Editor → جدول `gmt_settings`.
2. ابحث عن الصف `key = admin_password`.
3. القيمة بعمود `value` هي كلمة السر.
4. لتغييرها: عدّل `value` مباشرة.

**إن لم يوجد الصف:** الدخول يفشل دائماً. أضف صفاً:
`key = admin_password` · `value = (كلمة السر)`.

---

## 👑 الأدمن السيادي
يُدخل عبر مصادقة Supabase (بريد + كلمة سر).

---

## 🌐 أدمن الموقع
**مصادقة Supabase** (بريد + كلمة سر):
- Supabase → Authentication → Users → Add user.
- أنشئ بريداً وكلمة سر، واستعملهما بصفحة أدمن الموقع.

---

## 📊 وصول تقارير البوتات (للمالك)
- افتح الأدمن السيادي أو بوتات الحماية → زر «📊 تقارير النظام».
- أو أضف `?reports=1` لأي رابط.

---

## 🔧 وصول أدوات الفحص (للمالك)
- الأزرار مخفية عن المستخدم العادي.
- تظهر للمالك (دور admin/sovereign) أو بإضافة `?reports=1`.
- لإظهار كل الأزرار مؤقتاً (تشخيص): افتح Console واكتب `GMTVisibility.showAll()`.

---

## ⚠️ ملاحظة أمان
- لا تشارك كلمات السر بروابط عامة.
- غيّر admin_password دورياً من Supabase.
- كلمات سر Supabase Auth تُدار من لوحة Supabase فقط.
